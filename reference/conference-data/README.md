# Conference Data Service Reference

Index of Apps Script Conference Data service classes and enums.

- [ConferenceDataService](./ConferenceDataService.md) — Service that scripts can use to create conferencing information.
- [ConferenceData](./ConferenceData.md) — Container for all conference-related information.
- [ConferenceDataBuilder](./ConferenceDataBuilder.md) — A builder used to create ConferenceData objects.
- [ConferenceError](./ConferenceError.md) — Error that occurred in a conferencing add-on.
- [ConferenceParameter](./ConferenceParameter.md) — A solution-specific parameter for add-ons that is persisted with conference data.
- [EntryPoint](./EntryPoint.md) — Definition of a specific way to join a conference.
- [ConferenceErrorType](./ConferenceErrorType.md) — Enum of conference error types (AUTHENTICATION, CONFERENCE_SOLUTION_FORBIDDEN, PERMANENT, PERMISSION_DENIED, TEMPORARY, UNKNOWN).
- [EntryPointFeature](./EntryPointFeature.md) — Enum of entry point features (UNKNOWN_FEATURE, TOLL, TOLL_FREE).
- [EntryPointType](./EntryPointType.md) — Enum of entry point types (VIDEO, PHONE, MORE, SIP).
