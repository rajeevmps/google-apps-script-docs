# Contacts Service Reference (Legacy, Deprecated)

Index of Apps Script Contacts service classes and enums. The entire Contacts service is deprecated; Google recommends using the People API advanced service instead.

- [ContactsApp](./ContactsApp.md) — Allows users to access their own Google Contacts and create, remove, and update contacts.
- [AddressField](./AddressField.md) — Address field in a contact.
- [CompanyField](./CompanyField.md) — A company field in a Contact.
- [Contact](./Contact.md) — A Contact contains the name, address, and various contact details of a contact.
- [ContactGroup](./ContactGroup.md) — A ContactGroup is a group of contacts.
- [CustomField](./CustomField.md) — A custom field in a Contact.
- [DateField](./DateField.md) — A date field in a Contact.
- [EmailField](./EmailField.md) — An email field within a Contact.
- [IMField](./IMField.md) — An instant messaging field in a Contact.
- [PhoneField](./PhoneField.md) — A phone number field in a Contact.
- [UrlField](./UrlField.md) — A URL field in a Contact.
- [ExtendedField](./ExtendedField.md) — Enum for extended contacts fields (HOBBY, MILEAGE, LANGUAGE, GENDER, etc.).
- [Field](./Field.md) — Enum for standard contact fields (FULL_NAME, GIVEN_NAME, HOME_ADDRESS, etc.).
- [Gender](./Gender.md) — Enum for contact gender (MALE, FEMALE).
- [Priority](./Priority.md) — Enum for contact priority (HIGH, LOW, NORMAL).
- [Sensitivity](./Sensitivity.md) — Enum for contact sensitivity (CONFIDENTIAL, NORMAL, PERSONAL, PRIVATE).
