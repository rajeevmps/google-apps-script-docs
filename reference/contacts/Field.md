# Field

An enum for standard contact fields. (Deprecated)

**Deprecated.** Use the [People API advanced service](https://developers.google.com/apps-script/advanced/people) instead.

An enum for standard contact fields, used as labels for contact detail fields such as addresses, emails, phone numbers, IM addresses, URLs, and dates.
