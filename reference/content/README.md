# Content Service

Index of the Google Apps Script Content Service reference documentation.

| Class | Description |
|---|---|
| [ContentService](ContentService.md) | Service for returning text content from a script, for example to publish as a web app response. |
| [TextOutput](TextOutput.md) | A text object that can be served from a script, redirected via googleusercontent.com. |
| [MimeType](MimeType.md) | Enum of MIME types that can be served via Content Service (CSV, ICAL, JAVASCRIPT, JSON, TEXT, VCARD). |
