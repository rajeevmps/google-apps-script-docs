# Base Service Reference

Offline local markdown copy of the Google Apps Script "Base" utility service reference documentation.

- [Browser](./Browser.md) — Provides access to dialog boxes specific to Google Sheets (inputBox, msgBox).
- [Logger](./Logger.md) — Writes to the Execution log and Google Cloud Logging for structured logging.
- [MimeType](./MimeType.md) — Enumeration providing access to MIME-type declarations without typing the strings explicitly.
- [Session](./Session.md) — Provides access to session information, such as the user's email address and language setting.
- [console](./console.md) — Writes to the Execution log and Google Cloud Logging, serializing objects to strings.
- [Blob](./Blob.md) — A data interchange object for Apps Script services.
- [Menu](./Menu.md) — A custom menu in an instance of the user interface for a Google App.
- [PromptResponse](./PromptResponse.md) — A response to a prompt dialog displayed in the user-interface environment for a Google App.
- [RgbColor](./RgbColor.md) — A color defined by red, green, blue color channels.
- [Ui](./Ui.md) — An instance of the user-interface environment for a Google App (menus, dialogs, sidebars).
- [User](./User.md) — Representation of a user, suitable for scripting.
- [BlobSource](./BlobSource.md) — Interface for objects that can export their data as a Blob.
- [Button](./Button.md) — Enum representing predetermined, localized dialog buttons returned by an alert or prompt response.
- [ButtonSet](./ButtonSet.md) — Enum representing predetermined, localized sets of dialog buttons for an alert or prompt.
- [ColorType](./ColorType.md) — The types of Colors (UNSUPPORTED, RGB, THEME).
- [Month](./Month.md) — Enum representing the months of the year.
- [Weekday](./Weekday.md) — Enum representing the days of the week.
