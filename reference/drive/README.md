# Drive Service Reference

Index of Google Apps Script Drive service classes and enums.

- [DriveApp](./DriveApp.md) — Allows scripts to create, find, and modify files and folders in Google Drive.
- [File](./File.md) — A file in Google Drive.
- [FileIterator](./FileIterator.md) — An iterator that allows scripts to iterate over a potentially large collection of files.
- [Folder](./Folder.md) — A folder in Google Drive.
- [FolderIterator](./FolderIterator.md) — An object that allows scripts to iterate over a potentially large collection of folders.
- [User](./User.md) — A user associated with a file in Google Drive.
- [Access](./Access.md) — An enum representing classes of users who can access a file or folder.
- [Permission](./Permission.md) — An enum representing the permissions granted to users who can access a file or folder.
