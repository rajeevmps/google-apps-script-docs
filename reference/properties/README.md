# Properties Service Reference

Offline local markdown copy of the Google Apps Script Properties service reference documentation.

- [PropertiesService](./PropertiesService.md) — Allows scripts to store simple data in key-value pairs scoped to one script, one user of a script, or one document in which an add-on is used.
- [Properties](./Properties.md) — The interface returned by PropertiesService's getScriptProperties(), getUserProperties(), and getDocumentProperties() methods, used to get, set, and delete key-value pairs in a properties store.
- [ScriptProperties](./ScriptProperties.md) — Deprecated legacy class for script-scoped key-value pairs; superseded by PropertiesService.getScriptProperties().
- [UserProperties](./UserProperties.md) — Deprecated legacy class for user-scoped key-value pairs; superseded by PropertiesService.getUserProperties().
