# Data Studio (Looker Studio Connectors) Service Reference

Index of Apps Script Data Studio (community connector) service classes and enums.

- [DataStudioApp](./DataStudioApp.md) — Allows scripts to interact with developer-oriented features for Data Studio.
- [BigQueryConfig](./BigQueryConfig.md) — A configuration object for a native BigQuery connector.
- [Checkbox](./Checkbox.md) — Contains checkbox information for the config.
- [CommunityConnector](./CommunityConnector.md) — Enables scripts to access builders and utilities for developing Community Connectors.
- [Config](./Config.md) — Contains the configuration entries for a connector.
- [DebugError](./DebugError.md) — An error that is only visible to admins of the connector.
- [Field](./Field.md) — Contains field-related data determining how a field is used in Data Studio.
- [Fields](./Fields.md) — Contains a set of Fields for a community connector.
- [GetAuthTypeResponse](./GetAuthTypeResponse.md) — Builder to create a getAuthType() response.
- [GetDataResponse](./GetDataResponse.md) — Builder to create a getData() response.
- [GetSchemaResponse](./GetSchemaResponse.md) — Builder to create a getSchema() response.
- [Info](./Info.md) — Contains info entry data for the config.
- [OptionBuilder](./OptionBuilder.md) — A builder for creating options for SelectSingles and SelectMultiples.
- [SelectMultiple](./SelectMultiple.md) — Contains select multiple information for the config.
- [SelectSingle](./SelectSingle.md) — Contains configuration information for how a select single is displayed.
- [SetCredentialsResponse](./SetCredentialsResponse.md) — Builder to create a setCredentials() response.
- [TextArea](./TextArea.md) — Contains text area information for the config.
- [TextInput](./TextInput.md) — Contains text input information for the config.
- [UserError](./UserError.md) — An error shown to users of the connector.
- [AggregationType](./AggregationType.md) — Enum of aggregation types applicable to a Field (AVG, COUNT, SUM, etc.).
- [AuthType](./AuthType.md) — Enum of authentication types available for connector configuration.
- [BigQueryParameterType](./BigQueryParameterType.md) — Enum of BigQuery parameter types (STRING, INT64, BOOL, FLOAT64).
- [FieldType](./FieldType.md) — Enum of field types that can be set for a Field (dates, geography, numbers, currencies, etc.).
