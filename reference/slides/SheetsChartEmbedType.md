# SheetsChartEmbedType

The Sheets chart's embed type.

The Sheets chart's embed type.

To call an enum, you reference its parent class, name, and property. For example: `SlidesApp.SheetsChartEmbedType.IMAGE`.

## Values

- `UNSUPPORTED` — Represents a chart that is not supported and cannot be further classified.
- `IMAGE` — Indicates that the chart is embedded as an image.
