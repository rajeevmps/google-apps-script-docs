# SlideLinkingMode

The mode of links between slides.

The mode of links between slides.

To access this enum, use the syntax: `SlidesApp.SlideLinkingMode.LINKED`

## Values

- `UNSUPPORTED` — A slide linking mode that isn't supported.
- `LINKED` — Indicates that slides are linked.
- `NOT_LINKED` — Indicates that slides aren't linked.
