# PageType

The page types.

The page types. This enum represents different page type categories available in Google Slides presentations.

To call an enum, you call its parent class, name, and property. For example, `SlidesApp.PageType.SLIDE`.

## Values

- `UNSUPPORTED` — A page type that is not supported.
- `SLIDE` — A slide page.
- `LAYOUT` — A layout page.
- `MASTER` — A master page.
