# TextBaselineOffset

The text vertical offset from its normal position.

The text vertical offset from its normal position.

To call an enum, use the format: `SlidesApp.TextBaselineOffset.PROPERTY_NAME`

## Values

- `UNSUPPORTED` — A text baseline offset that is not supported.
- `NONE` — The text is not vertically offset.
- `SUPERSCRIPT` — The text is vertically offset upwards.
- `SUBSCRIPT` — The text is vertically offset downwards.
