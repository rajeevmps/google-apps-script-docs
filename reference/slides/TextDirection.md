# TextDirection

The directions text can flow in.

The directions text can flow in.

To call this enum, use the format: `SlidesApp.TextDirection.LEFT_TO_RIGHT`

## Values

- `UNSUPPORTED` — A text direction that is not supported.
- `LEFT_TO_RIGHT` — The text goes from left to right.
- `RIGHT_TO_LEFT` — The text goes from right to left.
