# PlaceholderType

The placeholder types.

The placeholder types. Many of these placeholder types correspond to placeholder IDs from the ECMA-376 standard, specifically ST_PlaceholderType in section 19.7.10 of the ECMA-376 5th edition specification.

Values are accessed via: `SlidesApp.PlaceholderType.PROPERTY_NAME`

## Values

- `UNSUPPORTED` — A placeholder type that is not supported.
- `NONE` — Not a Placeholder.
- `BODY` — Body text.
- `CHART` — Chart or graph.
- `CLIP_ART` — Clip art image.
- `CENTERED_TITLE` — Title centered.
- `DIAGRAM` — Diagram.
- `DATE_AND_TIME` — Date and time.
- `FOOTER` — Footer text.
- `HEADER` — Header text.
- `MEDIA` — Multimedia.
- `OBJECT` — Any content type.
- `PICTURE` — Picture.
- `SLIDE_NUMBER` — Number of a slide.
- `SUBTITLE` — Subtitle.
- `TABLE` — Table.
- `TITLE` — Slide title.
- `SLIDE_IMAGE` — Slide image.
