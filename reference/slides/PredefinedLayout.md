# PredefinedLayout

Predefined layouts.

Predefined layouts. These are commonly found layouts in presentations. However, there is no guarantee that these layouts are present in the current master as they could have been deleted or not part of the used theme. Additionally, the placeholders on each layout may have been changed.

## Values

- `UNSUPPORTED` — A layout that is not supported.
- `BLANK` — Blank layout, with no placeholders. Matches the "Blank" layout in the Google Slides UI.
- `CAPTION_ONLY` — Layout with a caption at the bottom. Matches the "Caption" layout in the Google Slides UI.
- `TITLE` — Layout with a title and a subtitle. Matches the "Title slide" layout in the Google Slides UI.
- `TITLE_AND_BODY` — Layout with a title and body. Matches the "Title and body" layout in the Google Slides UI.
- `TITLE_AND_TWO_COLUMNS` — Layout with a title and two columns. Matches the "Title and two columns" layout in the Google Slides UI.
- `TITLE_ONLY` — Layout with only a title. Matches the "Title only" layout in the Google Slides UI.
- `SECTION_HEADER` — Layout with a section title. Matches the "Section header" layout in the Google Slides UI.
- `SECTION_TITLE_AND_DESCRIPTION` — Layout with a title and subtitle on one side and description on the other.
- `ONE_COLUMN_TEXT` — Layout with one title and one body, arranged in a single column.
- `MAIN_POINT` — Layout with a main point. Matches the "Main point" layout in the Google Slides UI.
- `BIG_NUMBER` — Layout with a big number heading. Matches the "Big number" layout in the Google Slides UI.
