# SpacingMode

The different modes for paragraph spacing.

The different modes for paragraph spacing.

To call an enum, you reference its parent class, name, and property. For example: `SlidesApp.SpacingMode.NEVER_COLLAPSE`.

## Values

- `UNSUPPORTED` — A spacing mode that is not supported.
- `NEVER_COLLAPSE` — Paragraph spacing is always rendered.
- `COLLAPSE_LISTS` — Paragraph spacing is skipped between list elements.
