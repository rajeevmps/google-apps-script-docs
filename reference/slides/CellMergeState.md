# CellMergeState

The states of a table cell's merge status.

CellMergeState defines the possible states of a table cell's merge status. You can access values via `SlidesApp.CellMergeState.PROPERTY`.

## Values

- `NORMAL` — The cell is not merged.
- `HEAD` — The cell is merged and it is the head (for example, upper left) cell within the merged set of cells.
- `MERGED` — The cell is merged but is not the head (for example, upper left) cell.
