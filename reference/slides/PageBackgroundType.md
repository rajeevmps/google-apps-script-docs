# PageBackgroundType

The kinds of page backgrounds.

The kinds of page backgrounds. This enum defines the different background fill options available for slides in Google Slides presentations.

To call an enum value, use the parent class, name, and property. Example: `SlidesApp.PageBackgroundType.SOLID`

## Values

- `UNSUPPORTED` — A page background type that is not supported.
- `NONE` — No fill, so the background is rendered white.
- `SOLID` — A solid color fill.
- `PICTURE` — A picture that is stretched to fill the page.
