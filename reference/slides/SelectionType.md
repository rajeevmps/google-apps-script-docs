# SelectionType

The most specific type of one or more objects that are selected.

The `SelectionType` represents the most specific type of one or more objects that are selected. As an example if one or more `TableCell` instances are selected in a `Table`, the selection type is `SelectionType.TABLE_CELL`.

Access via: `SlidesApp.SelectionType.TEXT` (parent class, name, and property)

## Values

- `UNSUPPORTED` — A selection type that is not supported.
- `NONE` — No selection.
- `TEXT` — Text selection.
- `TABLE_CELL` — Table cell selection.
- `PAGE` — Page selection in the thumbnail flimstrip.
- `PAGE_ELEMENT` — Page element selection.
- `CURRENT_PAGE` — Current page selection.
