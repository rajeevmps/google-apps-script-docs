# PageElementRange

A collection of one or more PageElement instances.

"A collection of one or more `PageElement` instances."

## Methods

### getPageElements()

`PageElement[]`

Returns the list of `PageElement` instances.

**Returns**

`PageElement[]` — the page elements in this range.

**Authorization**

Scripts that use this method require authorization with one or more of the following scopes:
- `https://www.googleapis.com/auth/presentations.currentonly`
- `https://www.googleapis.com/auth/presentations`

## Properties

None.

Note: PageElementRange is used to work with collections of page elements within Google Slides presentations through the Apps Script API.
