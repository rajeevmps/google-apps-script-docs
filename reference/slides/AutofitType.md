# AutofitType

The autofit types.

The autofit types. To access these values, use `SlidesApp.AutofitType.PROPERTY_NAME`.

## Values

- `UNSUPPORTED` — An autofit type that is not supported.
- `NONE` — Autofit isn't applied.
- `TEXT_AUTOFIT` — Shrinks the text on overflow.
- `SHAPE_AUTOFIT` — Resizes the shape to fit the text.
