# SlidePosition

The relative position of a Slide.

The relative position of a `Slide`.

To call an enum, use the pattern: `SlidesApp.SlidePosition.NEXT_SLIDE`

## Values

- `NEXT_SLIDE` — The next slide.
- `PREVIOUS_SLIDE` — The previous slide.
- `FIRST_SLIDE` — The first slide in the presentation.
- `LAST_SLIDE` — The last slide in the presentation.
