# WrapStyle

An enum that sets the wrapping style for content within a column.

An enum that sets the wrapping style for content within a column. Available for Google Chat apps and Google Workspace add-ons.

To call an enum, you call its parent class, name, and property. For example, `CardService.WrapStyle.WRAP`.

## Properties

### NOWRAP
No wrapping. Default.

### WRAP
Wraps the content for any widgets in a column.
