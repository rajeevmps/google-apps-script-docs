# TextInputMode

An enum that defines the what type of input is allowed for the text input field.

An enum that defines the what type of input is allowed for the text input field. Only available for Google Workspace add-ons that extend Google Workspace Studio.

To call an enum, you call its parent class, name, and property. For example, `CardService.TextInputMode.PLAIN_TEXT`.

## Properties

### PLAIN_TEXT
Only allow plain text input.

### RICH_TEXT
Support both plain text input and variables in a text input.
