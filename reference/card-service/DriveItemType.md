# DriveItemType

An enum that defines the file type for a drive item.

An enum define the file type for a drive item.

To call an enum, you call its parent class, name, and property. For example, `CardService.DriveItemType.DOCUMENTS`.

## Properties

### DRIVE_ITEM_TYPE_UNSPECIFIED
Default value. Don't use.

### DOCUMENTS
Represents a Google Docs document.

### SPREADSHEETS
Represents a Google Sheets document.

### PRESENTATIONS
Represents a Google Slides document.

### PDFS
Represents a PDF document.

### FORMS
Represents a Google Forms document.

### FOLDERS
Represents a Google Drive folder.
