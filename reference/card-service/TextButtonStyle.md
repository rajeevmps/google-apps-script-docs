# TextButtonStyle

The style of a TextButton.

The style of a `TextButton`. OUTLINED is the default; it renders a simple text button with clear background. FILLED buttons have a background color you can set with `TextButton.setBackgroundColor(backgroundColor)`.

To call an enum, you call its parent class, name, and property. For example, `CardService.TextButtonStyle.OUTLINED`.

## Properties

### OUTLINED
Normal text button with clear background. Default.

### TEXT
DO NOT USE. Deprecated version of OUTLINED. Do not remove the field until it is confirmed not being used by any apps.

### FILLED
Text button with colored background.

### FILLED_TONAL
Normal text button with an alternative middle ground between filled and outlined buttons.

### BORDERLESS
Normal text button with no border.
