# ImageCropType

An enum that represents the crop style applied to an image.

An enum that represents the crop style applied to an image. If you want to apply a crop style to an `IconImage`, you can only use `SQUARE` or `CIRCLE`.

To call an enum, you call its parent class, name, and property. For example, `CardService.ImageCropType.SQUARE`.

## Properties

### SQUARE
Square shape crop style.

### CIRCLE
Circle shape crop style.

### RECTANGLE_CUSTOM
Rectangle shape crop style with custom ratio.

### RECTANGLE_4_3
Rectangle shape crop style with 4:3 ratio.
