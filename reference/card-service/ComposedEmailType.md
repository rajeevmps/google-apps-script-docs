# ComposedEmailType

An enum value that specifies the type of a composed email.

An enum value that specifies whether a composed email is a standalone or reply draft.

To call an enum, you call its parent class, name, and property. For example, `CardService.ComposedEmailType.REPLY_AS_DRAFT`.

## Properties

### REPLY_AS_DRAFT
A draft that is a reply to another message. Default.

### STANDALONE_DRAFT
A draft that is a standalone message.
