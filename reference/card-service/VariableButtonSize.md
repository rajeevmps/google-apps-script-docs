# VariableButtonSize

An enum that represents the size of the variable picker button.

An enum that represents the size of the variable picker button.

To call an enum, you call its parent class, name, and property. For example, `CardService.VariableButtonSize.COMPACT`.

## Properties

### UNSPECIFIED
Automatically chooses COMPACT for Sidepanel, chooses FULL_SIZE otherwise.

### COMPACT
For buttons labeled `+`

### FULL_SIZE
For buttons labeled `+ variable`
