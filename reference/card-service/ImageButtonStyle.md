# ImageButtonStyle

An enum that specifies styles for image buttons.

An enum that specifies styles for image buttons. BORDERLESS is the default; it renders a simple image button with no border. FILLED buttons have a background color you can set with ImageButton.

To call an enum, you call its parent class, name, and property. For example, `CardService.ImageButtonStyle.BORDERLESS`.

## Properties

### BORDERLESS
Image button with no border. Default.

### OUTLINED
Image button with clear background.

### FILLED
Image button with colored background.

### FILLED_TONAL
Image button with an alternative middle ground between filled and outlined buttons.
