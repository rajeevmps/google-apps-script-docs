# Visibility

An enum that represents the visibility state of the widgets.

An enum that represents the visibility state of the widgets. `Visibility.VISIBLE` means that the widget is being displayed and is visible. `Visibility.HIDDEN` means that the widget is not displayed and is invisible.

Only available for Google Workspace add-ons that extend Google Workspace Studio.

To call an enum, you call its parent class, name, and property. For example, `CardService.Visibility.VISIBLE`.

## Properties

### VISIBLE
The UI element is visible.

### HIDDEN
The UI element is invisible.

### VISIBILITY_UNSPECIFIED
The UI element is unspecified. Do not use.
