# ContentType

An enumeration representing the types of XML content nodes.

An enumeration representing the types of XML content nodes. To call an enum, you call its parent class, name, and property. For example, `XmlService.ContentTypes.CDATA`.

**Note:** On the live Google documentation site, this enum is actually named **ContentTypes** (plural) and is served at the URL slug `content-type` is a 404 — the working slug is `content-types` (https://developers.google.com/apps-script/reference/xml-service/content-types). The file is named `ContentType.md` to match the requested naming convention for this document set, but all references to the type within Apps Script code use `ContentTypes` (e.g. `XmlService.ContentTypes.ELEMENT`).
