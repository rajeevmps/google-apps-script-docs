# DateTimeGroupingRule

Access an existing date-time grouping rule.

Access an existing date-time grouping rule. To set a rule on PivotGroup, use `PivotGroup.setDateTimeGroupingRule(dateTimeGroupingRuleType)`.

## Methods

| Method | Return Type | Description |
|---|---|---|
| `getRuleType()` | `DateTimeGroupingRuleType` | Gets the type of the date-time grouping rule. Returns the rule type. |
