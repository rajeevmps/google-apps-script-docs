# ThemeColor

A representation for a theme color.

A representation for a theme color.

## Methods

### `getColorType()`

Get the type of this color.

**Returns:** ColorType — The color type.

**Authorization:** Requires one or more of the following scopes:
- `https://www.googleapis.com/auth/spreadsheets.currentonly`
- `https://www.googleapis.com/auth/spreadsheets`

### `getThemeColorType()`

Gets the theme color type of this color.

**Returns:** ThemeColorType — The theme color type.

**Authorization:** Requires one or more of the following scopes:
- `https://www.googleapis.com/auth/spreadsheets.currentonly`
- `https://www.googleapis.com/auth/spreadsheets`
