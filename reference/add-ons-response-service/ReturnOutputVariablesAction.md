# ReturnOutputVariablesAction

Contains output variables generated by the executed action in Google Workspace Studio.

Contains output variables generated by the executed action in Google Workspace Studio. Only available for Google Workspace add-ons that extend Google Workspace Studio.

## Methods

### addVariableData(key, value)

`addVariableData(key: String, value: VariableData): ReturnOutputVariablesAction`

Adds a variable data keyed by its variable name, a value is overwritten if the key already exists.

**Parameters**
- `key` (String) — The variable name of string type to retrieve the output variable data.
- `value` (VariableData) — The data of the variable.

**Returns**
- `ReturnOutputVariablesAction` — This return output variables action, for chaining.

### setLog(log)

`setLog(log: WorkflowTextFormat): ReturnOutputVariablesAction`

Sets the Log of the executed workflow action to the end user at Workflow's activity feed.

**Parameters**
- `log` (WorkflowTextFormat) — The WorkflowTextFormat log of the executed workflow action.

**Returns**
- `ReturnOutputVariablesAction` — This return output variables action, for chaining.

### setVariableDataMap(variables)

`setVariableDataMap(variables: Object): ReturnOutputVariablesAction`

Sets the map of the variable data keyed by variable name, a value is overwritten if the key already exists.

**Parameters**
- `variables` (Object) — A collection of key-value pairs of string and variable data.

**Returns**
- `ReturnOutputVariablesAction` — This return output variables action, for chaining.

## Code Sample

```javascript
const variableDataMap = {
  "result": AddOnsResponseService.newVariableData()
    .addIntegerValue(100)
};
const workflowAction = AddOnsResponseService.newReturnOutputVariablesAction()
  .setVariableDataMap(variableDataMap);

const hostAppAction = AddOnsResponseService.newHostAppAction()
  .setWorkflowAction(workflowAction);

const renderAction = AddOnsResponseService.newRenderActionBuilder()
  .setHostAppAction(hostAppAction)
  .build();

return renderAction;
```
