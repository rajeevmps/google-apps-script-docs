# ComposedEmailType

An enum value that specifies whether the composed email is a standalone or reply draft.

An enum value that specifies whether the composed email is a standalone or reply draft.

## Properties

| Property | Description |
|----------|-------------|
| `REPLY_AS_DRAFT` | A draft that is a reply to another message. Default. |
| `STANDALONE_DRAFT` | A draft that is a standalone message. |

## Usage Note

To access these enum values in code: `AddOnsResponseService.ComposedEmailType.REPLY_AS_DRAFT` or `AddOnsResponseService.ComposedEmailType.STANDALONE_DRAFT`
