# ErrorActionability

Represents the error actionability.

A Enum that represents the error actionability. The enum values are mapped to the proto enum values to provide the corresponding enum value support in AppScript.

## Properties

| Property | Description |
|----------|-------------|
| `ERROR_ACTIONABILITY_UNSPECIFIED` | Unspecified. |
| `NOT_ACTIONABLE` | The error is not fixable by the user through the configuration card. |
| `ACTIONABLE` | The error is fixable by the user through the configuration card. |
