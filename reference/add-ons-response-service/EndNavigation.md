# EndNavigation

An enum that specifies the action during navigation.

An enum that specifies the action during navigation. Available for Google Workspace add-ons that extend Google Chat.

## Properties

| Property | Description |
|----------|-------------|
| `ACTION_UNSPECIFIED` | Action unspecified. |
| `CLOSE_DIALOG` | Closes a dialog. |
| `CLOSE_DIALOG_AND_EXECUTE` | Closes a dialog and refreshes the card that opened the dialog. |
