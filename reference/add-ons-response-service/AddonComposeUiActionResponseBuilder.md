# AddonComposeUiActionResponseBuilder

A builder for `AddonComposeUiActionResponse` objects.

A builder for `AddonComposeUiActionResponse` objects.

## Methods

### build()

`build(): AddonComposeUiActionResponse`

Builds the current addon compose ui action response and validates it.

**Throws:** `Error` if the constructed AddonComposeUiActionResponse isn't valid.

### setType(type)

`setType(type: AddonComposeUiActionType): AddonComposeUiActionResponseBuilder`

Sets the enum field that determines the addon compose ui action.

**Parameters**
- `type` (AddonComposeUiActionType): The enum that indicates the addon compose ui action to take.
