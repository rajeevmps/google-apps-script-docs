# BasicDataType

An enum that represents the basic generic data types.

An enum that represents the basic generic data types.

## Properties

| Property | Description |
|----------|-------------|
| `BASIC_TYPE_UNSPECIFIED` | Default value. Don't use. |
| `STRING` | A string of characters. |
| `INTEGER` | An integer value. |
| `FLOAT` | A floating point number. |
| `TIMESTAMP` | A timestamp in ISO 8601 format. |
| `BOOLEAN` | A boolean value. |
| `EMAIL_ADDRESS` | A string in the format of an email address. |
| `GOOGLE_USER` | A user of the Google services, in the format of "users/encoded_GAIA_ID". |
| `FILE` | A file type. |
| `FORMATTED_TEXT` | A text with rich formatting. |
