# Calendar Service Reference

Index of Google Apps Script Calendar service classes and enums.

- [CalendarApp](./CalendarApp.md) — Allows a script to read and update the user's Google Calendar.
- [Calendar](./Calendar.md) — A calendar that the user owns or is subscribed to.
- [CalendarEvent](./CalendarEvent.md) — Represents a single calendar event.
- [CalendarEventSeries](./CalendarEventSeries.md) — Represents a series of events (a recurring event).
- [EventGuest](./EventGuest.md) — Represents a guest of an event.
- [EventRecurrence](./EventRecurrence.md) — Represents the recurrence settings for an event series.
- [RecurrenceRule](./RecurrenceRule.md) — Represents a recurrence rule for an event series.
- [Color](./Color.md) — An enum representing the named colors available in the Calendar service.
- [EventColor](./EventColor.md) — An enum representing the named event colors available in the Calendar service.
- [EventTransparency](./EventTransparency.md) — An enum representing the transparency of an event.
- [EventType](./EventType.md) — An enum representing the type of an event.
- [GuestStatus](./GuestStatus.md) — An enum representing the statuses a guest can have for an event.
- [Visibility](./Visibility.md) — An enum representing the visibility of an event.
