# Gmail Service Reference

Index of Google Apps Script Gmail service classes.

- [GmailApp](./GmailApp.md) — Provides access to Gmail threads, messages, and labels.
- [GmailAttachment](./GmailAttachment.md) — A Blob with an extra getSize() method that is faster and does not count against the Gmail read quota.
- [GmailDraft](./GmailDraft.md) — A user-created draft message in a user's Gmail account.
- [GmailLabel](./GmailLabel.md) — A user-created label in a user's Gmail account.
- [GmailMessage](./GmailMessage.md) — A message in a user's Gmail account.
- [GmailThread](./GmailThread.md) — A thread in a user's Gmail account.
