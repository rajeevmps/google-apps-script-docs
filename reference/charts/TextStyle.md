# TextStyle

A text style configuration object.

A text style configuration object. Used in charts options to configure text style for elements that accepts it, such as title, horizontal axis, vertical axis, legend and tooltip.

## Methods

### getColor()

Returns: `String`

Gets the color of the text style. Returns the CSS value for the color (such as `"blue"` or `"#00f"`).

### getFontName()

Returns: `String`

Gets the font name of the text style. Returns the font name.

### getFontSize()

Returns: `Number`

Gets the font size of the text style. Returns the font size in pixels.

## Properties

None.
