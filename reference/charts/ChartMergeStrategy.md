# ChartMergeStrategy

An enumeration of how multiple ranges in the source are expressed in a chart.

An enumeration of how multiple ranges in the source are expressed in a chart. To reference this enum, use the format: `Charts.ChartMergeStrategy.PROPERTY_NAME`.
