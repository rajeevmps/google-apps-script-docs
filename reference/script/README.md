# Apps Script Reference — Script Service

Offline markdown reference for the Google Apps Script "Script" service (`ScriptApp` and related classes/enums).

- [ScriptApp](./ScriptApp.md) — Access and manipulate script publishing and triggers.
- [AuthorizationInfo](./AuthorizationInfo.md) — Checks if the user has granted authorization for the required scopes of the script and provides an authorization URL.
- [CalendarTriggerBuilder](./CalendarTriggerBuilder.md) — Builder for calendar triggers.
- [ClockTriggerBuilder](./ClockTriggerBuilder.md) — A builder for clock (time-based) triggers.
- [DocumentTriggerBuilder](./DocumentTriggerBuilder.md) — A builder for document triggers.
- [FormTriggerBuilder](./FormTriggerBuilder.md) — A builder for form triggers.
- [Service](./Service.md) — Access and manipulate script publishing as a web app.
- [SpreadsheetTriggerBuilder](./SpreadsheetTriggerBuilder.md) — Builder for spreadsheet triggers.
- [StateTokenBuilder](./StateTokenBuilder.md) — Allows scripts to create state tokens used in callback APIs (like OAuth flows).
- [Trigger](./Trigger.md) — A script trigger.
- [TriggerBuilder](./TriggerBuilder.md) — A generic builder for script triggers.
- [AuthMode](./AuthMode.md) — Enumeration identifying which categories of authorized services Apps Script can execute through a triggered function.
- [AuthorizationStatus](./AuthorizationStatus.md) — Enumeration denoting the authorization status of a script.
- [EventType](./EventType.md) — Enumeration denoting the type of triggered event.
- [InstallationSource](./InstallationSource.md) — Enumeration denoting how the script was installed to the user as an add-on.
- [TriggerSource](./TriggerSource.md) — Enumeration denoting the source of the event that causes the trigger to fire.
