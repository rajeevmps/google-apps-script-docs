# Groups Service Reference

Index of Apps Script Groups service classes.

- [GroupsApp](./GroupsApp.md) — Provides access to Google Groups information, such as a group's email address or the list of groups a user directly belongs to.
- [Group](./Group.md) — A group object whose members and those members' roles within the group can be queried.
- [Role](./Role.md) — Enum of possible roles of a user within a group (OWNER, MANAGER, MEMBER, INVITED, PENDING, BANNED).
