# MarkerSize

An enum representing the size of a marker added to a map.

An enum representing the size of a marker added to a map. To access enum values, use the syntax `Maps.MarkerSize.PROPERTY`.

## Properties (Enum Values)

| Property | Description |
|----------|--------------|
| `TINY` | Tiny sized markers (smallest available). Labels will not be visible on markers of this size. |
| `MID` | Medium sized markers (largest available). |
| `SMALL` | Small sized markers. Labels will not be visible on markers of this size. |

The enum documentation references the Google Static Maps API marker styles documentation.
