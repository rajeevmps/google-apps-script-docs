# Maps Service Reference

Index of Apps Script Maps service classes and enums.

- [Maps](./Maps.md) — Allows for direction finding, geocoding, elevation sampling and the creation of static map images.
- [DirectionFinder](./DirectionFinder.md) — Allows for the retrieval of directions between locations.
- [DirectionFinderEnums](./DirectionFinderEnums.md) — A collection of enums used by DirectionFinder (Avoid, Mode).
- [ElevationSampler](./ElevationSampler.md) — Allows for the sampling of elevations at particular locations.
- [Geocoder](./Geocoder.md) — Allows for the conversion between an address and geographical coordinates.
- [StaticMap](./StaticMap.md) — Allows for the creation and decoration of static map images.
- [StaticMapEnums](./StaticMapEnums.md) — A collection of enums used by StaticMap (Color, Format, MarkerSize, Type).
- [Avoid](./Avoid.md) — Enum of restriction types to avoid when finding directions (TOLLS, HIGHWAYS).
- [Color](./Color.md) — Enum of named colors available for map images.
- [Format](./Format.md) — Enum of map image formats (PNG, PNG8, PNG32, GIF, JPG, JPG_BASELINE).
- [MarkerSize](./MarkerSize.md) — Enum of marker sizes (TINY, MID, SMALL).
- [Mode](./Mode.md) — Enum of travel modes for directions (DRIVING, WALKING, BICYCLING, TRANSIT).
- [Type](./Type.md) — Enum of map render types (ROADMAP, SATELLITE, TERRAIN, HYBRID).
