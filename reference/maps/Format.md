# Format

An enum representing the format of the map image.

An enum representing the format of the map image. To use it, call the parent class with the property, e.g. `Maps.Format.PNG`.

## Properties (Enum Values)

| Property | Description |
|----------|--------------|
| `PNG` | 8-bit PNG format. |
| `PNG8` | 8-bit PNG format. |
| `PNG32` | 32-bit PNG format. |
| `GIF` | GIF format. |
| `JPG` | JPEG format. |
| `JPG_BASELINE` | Non-progressive JPEG format. |

This enum correlates with the Google Static Maps API image format specifications.
