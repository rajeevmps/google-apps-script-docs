# Utilities Service Reference

Offline local copy of the Google Apps Script "Utilities" service reference documentation.

Source: https://developers.google.com/apps-script/reference/utilities/

- [Utilities](./Utilities.md) — This service provides utilities for string encoding/decoding, date formatting, JSON manipulation, and other miscellaneous tasks.
- [Charset](./Charset.md) — A typesafe enum for character sets.
- [DigestAlgorithm](./DigestAlgorithm.md) — Selector of Digest algorithm.
- [MacAlgorithm](./MacAlgorithm.md) — Selector of MAC algorithm.
- [RsaAlgorithm](./RsaAlgorithm.md) — Selector of RSA algorithm.
