# HorizontalAlignment

Enumeration of supported horizontal alignment types.

The `HorizontalAlignment` enumeration represents supported horizontal alignment types in Google Apps Script. To call an enum, reference its parent class, name, and property—for example, `DocumentApp.HorizontalAlignment.LEFT`. This enumeration manipulates alignment of `Paragraph` contents within documents.

## Properties

- **LEFT** — The left-alignment option.
- **CENTER** — The center-alignment option.
- **RIGHT** — The right-alignment option.
- **JUSTIFY** — The justify-alignment option.
