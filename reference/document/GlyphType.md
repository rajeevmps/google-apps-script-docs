# GlyphType

Enumeration defining supported glyph types for list items.

`GlyphType` is an enumeration defining supported glyph types for list items in Google Docs. Access specific glyph types by calling the parent class, name, and property—for example, `DocumentApp.GlyphType.BULLET`. Use this enumeration to set the bullet type for list items.

## Properties

- **BULLET** — The default bullet, circular and filled.
- **HOLLOW_BULLET** — A hollow bullet.
- **SQUARE_BULLET** — A square bullet.
- **NUMBER** — A number based bullet.
- **LATIN_UPPER** — A latin, uppercase bullet.
- **LATIN_LOWER** — A latin, lowercase bullet.
- **ROMAN_UPPER** — A roman numeral, uppercase bullet.
- **ROMAN_LOWER** — A roman numeral, lowercase bullet.
