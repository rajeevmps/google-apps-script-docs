# VerticalAlignment

Enumeration of supported vertical alignment types.

VerticalAlignment is an enumeration of supported vertical alignment types. You call an enum by calling its parent class, name, and property, such as `DocumentApp.VerticalAlignment.BOTTOM`. The VerticalAlignment enumeration is used to set the vertical alignment of table cells.

## Properties

- **BOTTOM** — The bottom-alignment option.
- **CENTER** — The center-alignment option.
- **TOP** — The top-alignment option.
