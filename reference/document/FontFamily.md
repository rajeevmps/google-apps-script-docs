# FontFamily

Deprecated enumeration of supported font families.

The `FontFamily` enumeration is deprecated. The methods `getFontFamily()` and `setFontFamily(String)` now use string names for fonts instead of this enum. Although deprecated, it remains available for compatibility with older scripts.

Use the `FontFamily` enumeration to set the font for a range of text, element, or document.
