# TabType

Enumeration of all the tab types available in DocumentApp.

TabType is an enumeration of all the tab types available in DocumentApp. You can access TabType enum values by calling its parent class (DocumentApp), the enum name (TabType), and the property name. The `getType()` method can be used with a tab element to check its type against the TabType enumeration before casting. Currently, the only available TabType is `DOCUMENT_TAB`.

## Properties

- **DOCUMENT_TAB** — The type corresponding to `DocumentTab`.
