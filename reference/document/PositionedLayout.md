# PositionedLayout

Enumeration that specifies how to lay out a PositionedImage in relation to surrounding text.

An enumeration that specifies how to lay out a `PositionedImage` in relation to surrounding text. To call an enum, you call its parent class, name, and property. For example, `DocumentApp.PositionedLayout.ABOVE_TEXT`.

## Properties

- **ABOVE_TEXT** — The image is positioned above the text.
- **BREAK_BOTH** — The image breaks the text on the left and right.
- **BREAK_LEFT** — The image breaks the text on the left.
- **BREAK_RIGHT** — The image breaks the text on the right.
- **WRAP_TEXT** — The image is wrapped by text.
