# VariableType

Type of variables created by the engine.

Type of variables created by the engine. To call this enum, use `LinearOptimizationService.VariableType.INTEGER` or `LinearOptimizationService.VariableType.CONTINUOUS`.

## Methods

None.

## Properties

| Property | Type | Description |
|---|---|---|
| INTEGER | Enum | Type of variable that can only take integer values. |
| CONTINUOUS | Enum | Type of variable that can take any real value. |
