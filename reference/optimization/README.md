# Linear Optimization Service

Index of the Google Apps Script Linear Optimization Service reference documentation.

| Class | Description |
|---|---|
| [LinearOptimizationService](LinearOptimizationService.md) | Entry point service used to model and solve linear and mixed-integer linear programs. |
| [LinearOptimizationEngine](LinearOptimizationEngine.md) | The engine used to define variables, constraints, and objective, then solve a linear program. |
| [LinearOptimizationConstraint](LinearOptimizationConstraint.md) | Represents a single linear constraint in the model. |
| [LinearOptimizationSolution](LinearOptimizationSolution.md) | Represents the solution of a solved linear program. |
| [Status](Status.md) | Enum of solver result statuses (OPTIMAL, FEASIBLE, INFEASIBLE, UNBOUNDED, ABNORMAL, MODEL_INVALID, NOT_SOLVED). |
| [VariableType](VariableType.md) | Enum of variable types (INTEGER, CONTINUOUS). |
