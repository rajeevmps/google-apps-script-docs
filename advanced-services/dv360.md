# Display & Video 360 Service

Source: https://developers.google.com/apps-script/advanced/dv360

## Overview

The Display & Video 360 (DV360) service enables programmatic access to the DV360 API within Google Apps Script. "The Display & Video 360 (DV360) service lets you use the DV360 API in Google Apps Script."

This is classified as an advanced service and requires explicit enablement before implementation.

## Enabling the Service

The documentation notes this is "an advanced service that must be enabled before use." See the Apps Script advanced services guide (https://developers.google.com/apps-script/guides/services/advanced) for step-by-step activation procedures.

## Reference Documentation

Complete API reference materials are available at the [DV360 API reference documentation](https://developers.google.com/display-video/api/reference/rest). The service uses version 4 of the API and mirrors the same objects, methods, and parameters as the public API.

## Code Samples

### List Partners

```javascript
/**
 * Logs all of the partners available in the account.
 */
function listPartners() {
  try {
    const partners = DisplayVideo.Partners.list();

    if (partners.partners) {
      for (let i = 0; i < partners.partners.length; i++) {
        const partner = partners.partners[i];
        console.log(
          'Found partner with ID %s and name "%s".',
          partner.partnerId,
          partner.displayName,
        );
      }
    }
  } catch (e) {
    console.log("Failed with error: %s", e.error);
  }
}
```

### List Active Campaigns

```javascript
/**
 * Logs names and ID's of all active campaigns.
 * Note the use of paging tokens to retrieve the whole list.
 */
function listActiveCampaigns() {
  const advertiserId = "1234567";
  let result;
  let pageToken;
  try {
    do {
      result = DisplayVideo.Advertisers.Campaigns.list(advertiserId, {
        filter: 'entityStatus="ENTITY_STATUS_ACTIVE"',
        pageToken: pageToken,
      });
      if (result.campaigns) {
        for (let i = 0; i < result.campaigns.length; i++) {
          const campaign = result.campaigns[i];
          console.log(
            'Found campaign with ID %s and name "%s".',
            campaign.campaignId,
            campaign.displayName,
          );
        }
      }
      pageToken = result.nextPageToken;
    } while (pageToken);
  } catch (e) {
    console.log("Failed with error: %s", e.error);
  }
}
```

### Update Line Item Display Name

```javascript
/**
 * Updates the display name of a line item
 */
function updateLineItemName() {
  const advertiserId = "1234567";
  const lineItemId = "123456789";
  const updateMask = "displayName";

  const lineItemDef = {
    displayName: "New Line Item Name (updated from Apps Script!)",
  };

  try {
    const lineItem = DisplayVideo.Advertisers.LineItems.patch(
      lineItemDef,
      advertiserId,
      lineItemId,
      { updateMask: updateMask },
    );
  } catch (e) {
    console.log("Failed with error: %s", e.error);
  }
}
```
