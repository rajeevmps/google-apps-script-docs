# Extend Google Chat

Google Workspace add-ons extend Chat by allowing developers to preview links, automate tasks, and receive alerts. These add-ons function as Chat apps, enabling interactions such as sending messages, responding to commands, and opening dialogs.

## Key Capabilities

Chat add-ons empower users to:

- Preview links from messages and take action without leaving conversations
- Automate tasks across Google Workspace applications
- Receive alerts about external tools or services

## How They Work

In Chat, add-ons can:

- Send messages with text, cards, and interactive UI elements
- Respond to quick and slash commands
- Open dialogs for multi-step processes
- Preview links with actionable cards

## Getting Started

Developers should consult:

- Quickstarts using Google Apps Script or HTTP services
- Chat app configuration documentation via the Chat API
- Interface-building guides covering triggers and actions

## Notable Limitations

Several features remain unavailable, including custom authorization cards, add-on homepages in Chat sidebars, and Chat app homepages. AppSheet architecture is also unsupported for Chat development.

## Configuration Requirements

For existing add-ons, marketplace installation settings must permit both individual and administrator installations. The Chat API's visibility setting replaces Marketplace SDK settings for deployment and testing.
